# INVENTORY MANAGEMENT APP

Welcome to my inventory management application! This app is designed to make managing and tracking both products and materials used to make them (and repurchasing those materials) much easier. Currently a work in progress, and is only planned to be used for jewelry, including necklaces, earrings, and bracelets; this may change in the future, but there are no plans for that currently.
